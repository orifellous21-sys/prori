# Cinematic Quote Video Machine

Double-click:

```text
MAKE_VIDEO_NOW.bat
```

It creates:

```text
output\latest\video.mp4
output\latest\caption.txt
```

The video is made to be closer to the uploaded reference:

- dark classical background
- meaningful motivational quote
- better narrator voice using Microsoft David when available
- text chunks appearing as the narrator says them
- dramatic background music
- vertical MP4 ready for YouTube Shorts or Instagram Reels
